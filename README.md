# Eng. Youssef El Shahawy — Video Editor Portfolio

Static portfolio site (no build step). Open `index.html` or deploy the folder as-is.

## Structure
- `index.html` — the whole site (styles + scripts inside). Content is edited in the `CONFIG` object near the bottom of the file.
- `videos/` — the portfolio videos (names must match the `src` paths in `CONFIG`).

## Deploy on Vercel
1. Import this GitHub repo at vercel.com/new
2. Framework Preset: **Other** — leave Build Command and Output Directory empty
3. Deploy

## Editing content
In `index.html`, search for `const CONFIG` to change name, email, WhatsApp number, social links, project titles and descriptions.
